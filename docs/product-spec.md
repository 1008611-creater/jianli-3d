# 需求规格 · product-spec

## 用户是谁

刘曙宾（LIU Shubin），ANS＆CAU HUB 创始人。需要一份能直接体现"AI 全栈 + AIGC 产品化"能力的个人名片式网站。

**访客画像**：潜在客户、合作方、招聘方、同行。停留时间短，需要 10 秒内建立印象。

## 要解决什么问题

原方案依赖第三方 3D 简历平台，导出与绑定自定义域名需付费，且素材与场景数据托管在平台，不受自己控制。需要一个**完全自主**的等价方案。

## 最小可交付范围（本期）

1. 3D 人物模型首屏展示，支持指针视差。
2. 4 段叙事：封面 + 3 个经历章节，滚动驱动镜头运镜与聚焦（含景深变化）。
3. 贴纸系统：10 张贴纸按原始坐标贴合模型表面。
4. 视觉规格对齐原效果：深色背景 `#202020`、强调色 `#ffd9b3`、Bricolage Grotesque 字体、辉光 + 景深后处理。
5. 作品集横向画廊：3 个分区、14 个项目，可点击跳转。
6. 联系方式：GitHub / 微信 / 电话，微信与电话支持点击复制。
7. 响应式：桌面 / 平板 / 移动三档。
8. 载入屏与进度指示。

## 明确不做

- 不做后台编辑界面（数据改 `scene.json` 即可）。
- 不做多语言切换（当前为中英混排的内容风格）。
- 不做用户登录、评论、表单提交。
- 不接入任何第三方统计或追踪。
- 不复用、不内联任何第三方站点的专有代码。

## 核心用户流程

```
打开链接
  → 载入屏（模型加载中，展示进度）
  → 封面：3D 模型 + 姓名 + 头衔 + 联系方式
  → 向下滚动
      → 镜头推进至 stop 1：AIGC 作品集（景深对焦脸部/身体）
      → 镜头推进至 stop 2：全栈开发
      → 镜头推进至 stop 3：AI Agent 产品化（镜头仰视）
  → 继续滚动进入作品集画廊
  → 点击任意作品卡片跳转对应产品
  → 页脚
```

## 失败流程

| 场景 | 期望行为 |
|---|---|
| WebGL 不可用 | 展示 `<noscript>` 兜底内容，不黑屏 |
| 模型加载失败 | 载入屏给出可见错误，不无限转圈 |
| 剪贴板 API 不可用 | 弹出手动复制提示，不静默失败 |
| 移动端低性能 | 限制 dpr、可关闭后处理，优先保证可交互 |
| 用户开启"减少动效" | 关闭动画与镜头缓动 |

## 验收标准

| # | 标准 | 验证方式 |
|---|---|---|
| A1 | `npm run verify` 全绿 | 命令输出 |
| A2 | 构建产物中不含任何外部域名 | `grep -r "http" dist/` 检查 |
| A3 | 首屏 3D 模型可见且贴纸位置与原效果一致 | 与原页面截图逐项比对 |
| A4 | 滚动 4 段镜头运镜连续无跳变 | 人工滚动验证 |
| A5 | 景深随章节切换 | 观察焦点变化 |
| A6 | 作品集 14 项可点击且链接正确 | 逐项点击 |
| A7 | 移动端 375px 宽下无横向溢出 | DevTools 设备模拟 |
| A8 | 键盘 Tab 可达时间轴与所有链接 | 键盘操作 |
| A9 | 微信/电话点击后复制成功 | 点击后粘贴验证 |
| A10 | 全部文案与用户真实信息一致 | 与 `scene.json` 核对 |

## 安全与合规边界

- 无服务端、无凭证、无用户数据采集。
- 联系方式为用户主动提供的公开信息。
- 全部素材为用户自有，代码为原创实现。
- 不含任何第三方品牌标识或专有代码痕迹。
